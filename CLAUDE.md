# Проект: documents.darlean.kz

## Контекст

- Владелец проекта — Владимир, продукт Darlean. **Не разработчик**, терминалом пользуется недавно.
- Эта папка = **один сайт**: посадочная страница для поддомена `documents.darlean.kz`.
- Вторая страница (`agents.darlean.kz`) живёт в **отдельной папке и отдельном репозитории**. Из этой папки её не трогать никогда.
- На сайт льётся **платная реклама**. Прод должен быть рабочим всегда. Сломанный деплой = слитый бюджет.

## Инфраструктура

| Параметр | Значение |
|---|---|
| GitHub репозиторий | `darlean-documents` (приватный) |
| Vercel проект | `darlean-documents` |
| Боевой домен | `documents.darlean.kz` |
| Ветка прода | `main` |
| Деплой | автоматический при push в `main` |
| Временный URL | _заполнить после первого деплоя_ |

## Структура папки

```
index.html      — главная и единственная страница, всегда в корне
/assets         — картинки, видео, шрифты
CLAUDE.md       — этот файл
```

Структуру не усложнять. Это статический сайт, он таким и останется.

## Рабочий процесс

1. Я правлю дизайн в **Claude Design**.
2. Говорю тебе, что именно забрать.
3. Ты импортируешь через `/design` в **эту** папку.
4. Показываешь, что изменилось, простыми словами.
5. После моего «ок» — коммит и push в `main`.
6. Vercel деплоит сам. Ты даёшь ссылку на проверку.

## Правила общения

- По-русски, без технического жаргона. Если термин необходим — поясни в скобках.
- Перед каждым действием одним предложением скажи, что собираешься сделать.
- **Не выполняй несколько шагов подряд без моего подтверждения**, если я явно не сказал «делай всё сразу».
- Если что-то пошло не так — скажи прямо. Не чини молча и не скрывай ошибку.
- Не предлагай переписать сайт на React, Next.js или любой сборщик. Ответ заранее — нет.

## Правила работы с файлами

- Дизайн и тексты по своей инициативе **не менять**. Только то, что я попросил.
- `index.html` всегда в корне, имя не менять.
- Импорт из Claude Design **перезаписывает** `index.html`. Перед импортом убедись, что предыдущая версия закоммичена — иначе правки потеряются безвозвратно.
- Файлы не удалять без спроса.
- `.git`, `.vercel` и настройки проекта не трогать без явной просьбы.
- **DNS-зону `darlean.kz` не трогать никогда.** Домены Владимир привязывает сам.

## Чеклист перед каждым push

- [ ] Страница открывается локально без ошибок в консоли
- [ ] Метатеги на месте: `title`, `description`, `og:image`
- [ ] Коды аналитики и рекламные пиксели не пропали
- [ ] Целевая кнопка / форма работает
- [ ] Мобильная вёрстка не поехала
- [ ] Сообщение коммита понятное, по-русски

**Отдельно предупреждай меня**, если импорт из Claude Design затёр метатеги, счётчики аналитики или рекламные пиксели. Claude Design о них не знает и вычищает при каждом импорте. Это ломает рекламную кампанию, а заметно не сразу.

## Если прод сломался

Сразу скажи мне и предложи откат на предыдущий деплой в Vercel. **Не чини на живом сайте**, пока на него идёт трафик. Сначала откат, потом разбор.
